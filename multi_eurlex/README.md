# MultiEURLEX Text Classification

Проект по многометочной классификации текстов на англоязычном датасете MultiEURLEX. Реализовано несколько подходов к векторизации и обучению моделей.

## Методы

- Векторизация: CountVectorizer, TF-IDF, sentence-transformers/paraphrase-xlm-r-multilingual-v1, cointegrated/rubert-tiny2
- Модели: логистическая регрессия, полносвязная нейронная сеть (PyTorch)

## Стек

Python, PyTorch, scikit-learn, Hugging Face Datasets, sentence-transformers, NumPy, Matplotlib

## Запуск

Запуск и воспроизведение экспериментов осуществляется в Jupyter Notebook. Все блоки кода должны быть выполнены последовательно.
