# Deep Q-Network (DQN) для Atari Breakout

Этот проект представляет собой реализацию алгоритма Deep Q-Network (DQN) для обучения агента играть в игру Atari Breakout. Реализация включает ключевые компоненты оригинального подхода: буфер опыта, целевую сеть, стратегию выбора действий на основе ε-жадной политики, а также предобработку изображений и стекирование кадров.

## Описание проекта

Проект выполнен в учебных целях и демонстрирует, как можно реализовать DQN с использованием библиотеки PyTorch и среды Gymnasium. Код организован в виде Jupyter Notebook, в котором представлены все этапы — от инициализации среды до обучения и визуализации результатов.

## Основные особенности

- Реализация DQN с использованием:
  - Буфера опыта (experience replay)
  - Целевой сети (target network)
  - ε-жадной стратегии с линейным уменьшением ε
- Предобработка изображений: обрезка, преобразование в оттенки серого, нормализация
- Стекирование кадров (frame stacking) для учета динамики движения
- Обновление Q-функции
