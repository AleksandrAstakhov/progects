# Классификация тональности текста на SST-2

Данный проект реализует задачу бинарной классификации тональности текста с использованием моделей машинного и глубокого обучения: наивного байесовского классификатора, логистической регрессии и нейронной сети на PyTorch. В качестве набора данных используется SST-2 (Stanford Sentiment Treebank).

## Описание датасета

- **Название:** SST-2 (Stanford Sentiment Treebank)
- **Источник:** [GitHub (репозиторий Clairett)](https://github.com/clairett/pytorch-sentiment-classification)
- **Тип задачи:** Классификация текста (положительная/отрицательная тональность)

## Реализованные модели

- Наивный байесовский классификатор (с использованием TF-IDF)
- Логистическая регрессия
- Полносвязная нейронная сеть (на PyTorch)

## Особенности проекта

- Токенизация текста с помощью библиотеки `NLTK`
- Векторизация текста с помощью TF-IDF
- Использование предобученных эмбеддингов GloVe (300-мерные) через библиотеку `Gensim`
- Обучение нейросети с использованием планировщиков скорости обучения (`StepLR`, `ReduceLROnPlateau`)
- Оценка качества моделей с использованием метрик Accuracy и ROC AUC
- Достигнута точность свыше 86% на модели Naive Bayes

## Используемые технологии
